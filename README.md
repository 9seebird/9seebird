## 구본세 · 9seebird

이것저것 만들어 보는 걸 좋아하는 IT 운영 엔지니어.
Linux · Docker · nginx · FastAPI, 그리고 요즘은 LLM.
혼자 회사 전산을 맡으면서 사내 앱 9개를 묶은 AI 챗 포털을 만들어 운영 중입니다.

**지금 관심** — AX, LLM 애플리케이션, AI 인프라(모델 서빙 · 운영 · 비용 관리)
